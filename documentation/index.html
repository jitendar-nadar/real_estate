Introduction

Thank you for purchasing White-Label Real Estate Platform. This is a full-stack property listing application built with Next.js 14 TypeScript Tailwind CSS MongoDB NextAuth.

Key capabilities:

  • Public property website with search, filters, and detail pages
  • White-label branding via environment variables (no code edits per client)
  • Admin panel for properties and user management
  • User dashboard for listing owners
  • Role-based access: Super Admin, Admin, User
  • Property inquiry forms and admin leads management
  • Embedded Google Maps on property detail pages
  • Property image upload (local storage)
  • Optional email notifications on new inquiries (Resend)
  • SEO: sitemap, robots.txt, Open Graph metadata
  • Contact, Privacy, and Terms pages

Requirements

  • Node.js 18 or later (nodejs.org)
  • npm 9 or later (included with Node.js)
  • MongoDB 6+ — local install or MongoDB Atlas (free tier works)
  • A code editor (VS Code recommended)
  • Terminal / command line access

Installation

1. Extract the package

Unzip the downloaded file to your preferred location.

2. Install dependencies

cd real-estate-app
npm install

3. Configure environment

cp .env.example .env.local

Open .env.local and set at minimum:

MONGODB_URI=mongodb://localhost:27017
NEXTAUTH_SECRET=your-secret-at-least-32-characters-long
NEXTAUTH_URL=http://localhost:3000
NEXT_PUBLIC_SITE_URL=http://localhost:3000

4. Start development server

npm run dev

Open http://localhost:3000 in your browser.

If port 3000 is in use, Next.js will use the next available port. Update NEXTAUTH_URL and NEXT_PUBLIC_SITE_URL to match the port shown in the terminal.

White-label setup

Rebrand the entire site for each client by editing .env.local only — no code changes required.

Example: new client deployment

NEXT_PUBLIC_COMPANY_NAME=Sunrise Properties
NEXT_PUBLIC_PRIMARY_COLOR=#b45309
NEXT_PUBLIC_COMPANY_LOGO=/logo.png
NEXT_PUBLIC_COMPANY_TAGLINE=Luxury homes and commercial spaces across Maharashtra.
NEXT_PUBLIC_HERO_HEADLINE=Discover exceptional properties
NEXT_PUBLIC_HERO_SUBHEADLINE=Residential and commercial listings curated by our expert team.
NEXT_PUBLIC_CONTACT_PHONE=+91 98765 43210
NEXT_PUBLIC_CONTACT_EMAIL=hello@sunriseproperties.com
NEXT_PUBLIC_COMPANY_ADDRESS=45 Marine Drive, Mumbai 400002
NEXT_PUBLIC_SOCIAL_WHATSAPP=https://wa.me/919876543210

Adding a logo

  1. Place your logo file in the public/ folder (create it if missing), e.g. public/logo.png
  2. Set NEXT_PUBLIC_COMPANY_LOGO=/logo.png
  3. Restart the dev server or redeploy
If no logo is set, the company name is displayed as styled text in the header and footer.

MongoDB setup

Option A — Local MongoDB

# macOS (Homebrew)
brew install mongodb-community
brew services start mongodb-community

# .env.local
MONGODB_URI=mongodb://localhost:27017

Option B — MongoDB Atlas (cloud)

  1. Create a free cluster at mongodb.com/atlas
  2. Create a database user and allow your IP (or 0.0.0.0/0 for cloud deploys)
  3. Copy the connection string and set it in .env.local:
MONGODB_URI=mongodb+srv://user:password@cluster.mongodb.net/realestate

The database and collections are created automatically on first run.

Live preview (Vercel / production)

  1. Set SEED_DEMO_DATA=true in your host environment variables
  2. Deploy and visit the site once (first request seeds the database)
  3. Remove SEED_DEMO_DATA and redeploy after demo data is populated
Remove SEED_DEMO_DATA after bootstrapping a production site so demo accounts are not recreated if collections are cleared.

Managing properties

  1. Go to Admin → Properties
  2. Click Add property
  3. Fill in title, price, location, type, images (upload or URLs), and details
  4. Submit — the listing appears on the public site immediately

Managing users

  1. Go to Admin → Users
  2. Add, edit, or remove team members and listing owners

Production build

npm run build
npm start

Before building for production, ensure:

  • NEXTAUTH_SECRET is a strong random string (32+ characters)
  • NEXTAUTH_URL matches your live domain with HTTPS
  • NEXT_PUBLIC_SITE_URL matches your live domain
  • SEED_DEMO_DATA is removed after live preview is bootstrapped

Deployment

Vercel (recommended for Next.js)

  1. Push code to GitHub
  2. Import project at vercel.com
  3. Add environment variables: MONGODB_URI, NEXTAUTH_SECRET, NEXTAUTH_URL, NEXT_PUBLIC_SITE_URL
  4. For live preview: temporarily set SEED_DEMO_DATA=true, deploy, visit site, then remove
  5. Use MongoDB Atlas — allow 0.0.0.0/0 in Network Access for Vercel
  6. Verify: /api/health returns "status":"ok"

VPS (Ubuntu + PM2)

npm install
npm run build
pm2 start npm --name "real-estate" -- start
pm2 save

Put Nginx or Caddy in front for HTTPS. Set all env vars in your process manager or .env.local on the server.
