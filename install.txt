White-Label Real Estate Platform
================================

Thank you for your purchase!

QUICK START
-----------
1. Extract this ZIP
2. Open terminal in the "real-estate-app" folder
3. Run: npm install
4. Run: cp .env.example .env.local
5. Edit .env.local (MongoDB URI, NEXTAUTH_SECRET, URLs)
6. Run: npm run dev
7. Open http://localhost:3000

FULL DOCUMENTATION
------------------
Open documentation/index.html in your browser for the complete guide:
  - Environment variables
  - MongoDB Atlas setup
  - White-label branding
  - Vercel deployment
  - Admin panel usage

REQUIREMENTS
------------
  - Node.js 18+
  - npm 9+
  - MongoDB 6+ (local or MongoDB Atlas)
