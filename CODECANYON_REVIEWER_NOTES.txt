WHAT THIS ITEM IS
-----------------
A white-label property listing portal for real estate agencies — NOT a multi-vendor
marketplace. Buyers rebrand the entire site via .env.local without code changes.

STACK
-----
Next.js 14 · TypeScript · Tailwind CSS · MongoDB · NextAuth.js

REVIEWER TEST FLOW (~5 minutes)
-------------------------------
1. Browse homepage and /listings — sample properties with search & filters
2. Open a property → embedded Google Map → submit inquiry form
3. Login as Admin → /admin/inquiries — verify the lead appears
4. Admin → Agents → view demo agents; open a public profile at /agents
5. Admin → Properties → Add property → assign agent → upload images → save
6. Property detail → heart icon (favorite); login → /dashboard/favorites
7. /admin — dashboard stats

SETUP FOR BUYERS (~10 minutes)
------------------------------
See install.txt and documentation/index.html inside the package.
Requires: Node 18+, MongoDB 6+ (Atlas free tier works).

KEY FEATURES (v1.3.0)
---------------------
- Public listings site with search, filters, pagination
- Agent profiles (/agents) and admin agent management
- Save favorites (account + guest localStorage)
- Embedded Google Maps on property detail
- Property image upload (local /public/uploads)
- Inquiry/leads management in admin
- Email notifications via Resend (optional)
- Role-based admin + user dashboard
- White-label branding via environment variables
- REST API with JWT bearer tokens
- One-click demo bootstrap: /api/setup/demo
- SEO: sitemap, robots, Open Graph
